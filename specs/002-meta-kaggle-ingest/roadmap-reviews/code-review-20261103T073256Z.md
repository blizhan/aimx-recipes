## Standards

### S-03 — PARTIAL / residual minor: stable diagnostic classification remains incomplete

**Requirements:** Constitution VII machine-readable CLI; FR-002 locatable malformed-input errors; CLI contract stable error codes and redacted messages.

The original leakage case is fixed: R2-rerun `numeric_diagnostic` returns `csv_malformed`, `file=Teams.csv`, `column=CompetitionId`, `record_id=1001`, and `marker_leaked=false`. `membership_write_failure` returns `write_failed` and zero remaining manifests. Corrupt membership now reports a fixed message without DuckDB SQL. The suite also covers JSON/text redaction for the Teams numeric case.

Two current-tree counterexamples remain:

1. **Malformed message ID loses its source location and stable input code.** The new `malformed_message_id` probe changes the first `ForumMessages.Id` and its matching `ForumTopics.FirstForumMessageId` to the same synthetic marker. The join still resolves. `resolve.py:96` passes the invalid id through; `normalize.py:253` calls `int()` without the new safe conversion. CLI output is exit 1, `[{"code":"runtime_error","message":"An unexpected runtime error occurred during ingestion"}]`, with no file, column, line, or record id. Marker is absent, so this is a classification/attribution failure, not a reproduced leak.
2. **Native Parquet write failure bypasses `write_failed`.** The `native_duckdb_write_failure` probe puts a directory at the target of the real DuckDB COPY call. The writer raises `IOException`; CLI `__init__.py:125` catches only Python `OSError`, so `:152` falls back to `runtime_error`. No manifests remain. This is controlled writer-boundary fault injection using the actual writer, not a claim to have filled a real disk.

**Closure criterion:** validate all consumed numeric relationships with trustworthy source attribution, and classify native write failures at the writer boundary as `write_failed` while retaining redaction and rollback. Add these cases to JSON/text checks. Do not map every DuckDB exception indiscriminately to a write error.

The residual issue is downgraded from major to minor because the demonstrated sensitive-value exposure and Python write-error behavior are fixed; these counterexamples are failures to honor diagnostic contracts, with ingestion failing safely.
